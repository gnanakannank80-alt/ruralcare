From a farmer's report to a containment action

Reporting, vaccination, lab and response sit in one workflow, so nothing gets lost between the village and the district office.

  1. Report

    A farmer or para-vet sends species, signs, count, deaths and location, with an optional photo.

  2. Triage

    Vet-reviewed rules score the signs against a disease matrix. Notifiable and zoonotic diseases escalate automatically.

  3. Verify and sample

    The vet officer confirms, sends samples to the lab and starts containment.

  4. Track

    A dashboard shows the outbreak map, vaccination coverage, reporting delay and open cases.

Technology

Proven, low-cost, open-source parts. The auditable rule engine comes first; machine learning is added for photo, voice and trend risk.

Frontend
React PWA and Android app, offline-first with local sync
Backend
Python (FastAPI) for triage rules and case workflow
AI and ML
Rule engine, then ML for photo, voice and trend risk
Database
PostgreSQL with PostGIS for herd and geo data
Security
Firebase Authentication, role-based access, encryption
Messaging
SMS, IVR, USSD and a WhatsApp gateway for alerts
